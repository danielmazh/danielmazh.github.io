What these marks mean

  • Simple: one script, extension or page.
  • Medium: one app with a backend, or a pipeline I run by hand.
  • Complex: several services or agents in real use.
  • Live: people use it today.
  • Built: it works, but there is no public version to use.
  • In progress: still being built.
  • Open lock: the code is public on GitHub.
  • Closed lock: the code is private on GitHub. Opens for invited accounts.
  • Stamp: built for a client or an employer, so the details stay private. The picture shows the idea with invented data.
