מה זה עלה

השער חזק רק כמו הבדיקות שלו. מודל הקוד כותב אותן, לפעמים מספיקה בדיקה אחת שעוברת, וההגנה רק סופרת בדיקות, אז assertion שנחלש עובר.

  1. מודל חלש יכול להיראות כאילו סיים: הבדיקות בכלל לא רצו, או שהוא מחק את אלה שנכשלו.

    רק מעבר של test runner אמיתי נחשב. בדיקת תחביר, או הרצה שלא הצליחה להתחיל, מדווחות unverified ויוצאות עם קוד שגיאה. בניסיונות תיקון הבדיקות לקריאה בלבד, וחבילה שאיבדה בדיקות משוחזרת ורצה שוב.

    בתרשים: שער בדיקות

  2. ניסיונות חוזרים בעיוורון שורפים שעות, אבל עצירה מוקדמת מוותרת על כשלים שעוד סיבוב היה מתקן.

    הניסיונות עולים בסולם: תיקון, הבהרת המפרט, תכנון מחדש, פיצול העבודה. hash של הבדיקות הנכשלות והשגיאות עוצר את הריצה אם שום דבר לא השתנה אחרי הסלמה. אם הניסיון האחרון גרוע יותר, העץ הטוב ביותר שנמדד חוזר.

    בתרשים: לולאת ניסיונות

  3. הכותב והסוקר חולקים Mac אחד עם 48 GB, וכל החלפת מודל פירושה טעינה מחדש של הרבה גיגה.

    אני מקבע context קטן לכל תפקיד, גם דרך קובץ הגדרות של Aider, כי אחרת Aider בוחר גודל משלו. את keep-alive שולחים כמספר, כי בצורת מחרוזת המודל לא נשאר טעון.

    שני המודלים נשארים טעונים יחד, בערך 30 GB.

  4. מודל ה-reasoning יכול לבזבז את כל הפלט על חשיבה ולהחזיר טקסט ריק, וזה נקרא כסקירה שנכשלה.

    תשובה ריקה מנסה שוב עם פחות reasoning ותקציב פלט גדול יותר. אפשר גם לשחזר את הפסיקה מטקסט החשיבה. סקירה שעדיין לא שמישה מדולגת עם אזהרה, והרצת הבדיקות מכריעה.

    בתרשים: בודק

Local LLM Engine - README

מה זה CLI עם המצבים build, swarm, audit, think ו-brainstorm, ועם פקודות לטעינת מודלים ועצירתם, לקריאת צריכת טוקנים ולבדיקת ההתקנה. מגיע איתו גם מופע נפרד של Claude Code שמחובר למודלים מקומיים, עם שורת סטטוס ירוקה משלו וסט כלים מצומצם לפרומפט הרבה יותר קטן.

איך זה עובד במצב build הצוות עובר תכנון, קוד, סקירה, בדיקות ותיקון. עם until-pass הוא ממשיך לתקן עד שהבדיקות עוברות, או עד מגבלה של ניסיונות או זמן. swarm מפצל משימה ל-subagents ממוקדים ומאחד את התוצאות, כי במשימה גדולה למודל מקומי נגמר המקום בהקשר. audit לא נוגע בפרויקט וכותב רק את הדוח שלו.

איך זה רץ הכול רץ דרך Ollama על המחשב שלך. סקריפט התקנה אחד מקים את זה. הכותב עובד דרך Aider, ופרוקסי קטן סופר את הטוקנים שלו.
