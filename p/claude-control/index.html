The whole tool: server, page, watchdog and restore scripts, and the Chrome extension.

  • 1,990-line Python server and a 2,406-line single page
  • 31 API paths, Python standard library only
  • 2 zsh scripts for the watchdog and restore, plus a Chrome extension
  • No automated tests. Risky actions offer a dry run instead

What it cost

Status comes from reading CLI screen text and process lists. That needs no API, but a new wording in the CLI can break detection.

  1. Claude Code has no API for its running sessions, so the page must work out their state from outside.

    It finds session ids in the ps list, walks up to 12 parent pids to reach the tmux pane, and reads the pane text for the phone link and open dialogs. Transcript details are cached by mtime and size, and full text search runs grep -F in batches of 200 files, because that is faster than parsing the JSON.

  2. Automatic recovery can do harm. A restart may kill running work, and a watchdog may start a second daemon or loop while the network is down.

    A restart sends /exit and waits up to 25 seconds. If the pane shows background work, it cancels and asks me. The launchd watchdog runs every 60 seconds with a lock, checks twice 10 seconds apart, does nothing while the API is unreachable, and keeps the dead pane so the log shows why it stopped.

Claude Control README

What it is A Python server and an HTML page, in Hebrew and English, using only the standard library. It has eight pages: home, sessions and restore, session search, logs, new session, manage, usage monitor and guide.

How it works The server checks the machine and reads sessions, settings, skills and usage records from ~/.claude, and serves them on localhost. The home page shows one health bar with a button that fixes what it can. For the rest it shows a command to copy. You can reconnect a session, search all conversations, bring a stopped session back and build a new one.

How it runs An install script adds it as a launchd agent. With one more flag it adds a watchdog that keeps the remote control daemon alive and a script that restores sessions at login. Parts a machine does not have are detected and left out.
